# Defend the Arki

A tower defense game about system architecture. Place Load Balancers, Redis, Rate Limiters, WAFs, CDNs and Kafka to protect your base from DDoS, bots, Zero-Days and Black Friday traffic.

**Play:** https://defend.thearki.com (desktop or phone in landscape, English and Spanish)

## Feedback

- **In the game:** Title screen → **Feedback**, or **Feedback** in the pause menu. No account needed.
- **On GitHub:** open an [Issue](../../issues/new/choose) (Bug or Idea).

Please include the version. It is at the bottom right of the title screen.

## Code

The game is in [`system-defense/`](system-defense/). It is TypeScript with no framework, uses Canvas 2D and has no server. See [system-defense/README.md](system-defense/README.md) (in Spanish) for commands, tests and deployment.
